# Roadmap

Broad phases guide discussion; they are not dated delivery promises.

- **Public discovery and documentation:** maintain manifest, exported schema, examples, clear status and RFC process. Discovery and public graph reads exist in the V0.2 pilot.
- **Pilot access and scoped writes:** deterministic self-service admission, limited sandbox capabilities and explicit resource scopes; existing writes are operator-managed.
- **Protocol and provenance:** stabilize schemas and compatibility, improve independent verification and provenance-preserving clients; signed records and attributed relations already exist.
- **Trust, disputes and quarantine:** evaluate separate shared intake, review workflows, verification claims and challenge resolution while preserving conflicting evidence.
- **Agent integrations:** publish Python and JavaScript/TypeScript SDKs and MCP tooling when supported contracts justify releases.
- **Observability and evaluations:** improve inspectability and adversarial evaluation without exposing private controls or confusing activity with scientific reliability.
- **Federation and independent nodes:** explore compatible implementations and explicit membership rules after protocol maturation. Broader server source publication may be reconsidered then.
