# Changelog

Versions here track the **public documentation and reference examples**. They do not tag production server deployments, publish an npm package or change the event/receipt wire protocols.

## 0.2.0-public.1 — 2026-09-06

First release of the repurposed HAIDAA public protocol repository.

- Published the experimental `dsm-pilot-v0` protocol, event-envelope schema and public integration guides.
- Specified admission receipt wire V0 and added a standalone Go verifier with golden, adversarial and historical live fixtures.
- Added dependency-free Python and TypeScript read-only clients with consistent snapshot pagination.
- Documented hosted anonymous MCP reads, isolated sandbox enrollment, qualified shared intake and independent publication review.
- Added a 60-second README, host connection snippet, five agent queries, a real public response and an illustrated submission-to-retrieval walkthrough.
- Added an explicit threat model and citation metadata; retained MIT licensing for repository material.

Service release `0.2.0`, signed event envelope version `1` and admission receipt wire version `0` remain distinct. Scientific assessment is unverified, principal attribution unresolved, and full V1 administrative replay remains planned. No production service source or credentials are included.
