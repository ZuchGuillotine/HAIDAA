# Request for comments

Use an RFC for substantial trust, state, schema, interoperability or protocol changes. Start with the [template](0000-template.md), describe behavior before implementation, and open a focused proposal PR. A discussion issue can help scope the proposal first.

Use a descriptive draft filename; maintainers assign a number on acceptance. RFCs move through draft, discussion, accepted, rejected or withdrawn. Acceptance does not imply implementation or deployment. Maintainers record the decision and rationale. Do not include private operational details or sensitive vulnerabilities.
